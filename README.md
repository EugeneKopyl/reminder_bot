# Reminder Bot

Telegram-бот для напоминаний. Надиктуйте голосом или напишите одной фразой, что и когда напомнить, — бот поймёт, сохранит и напомнит вовремя.

## Возможности

- Голосовой и текстовый ввод на естественном языке: «завтра в 9 позвонить маме», «по будням в 8 и в 20 таблетки».
- Однократные и повторяющиеся напоминания с гибким расписанием, в том числе «через 3 дня после выполнения».
- Подтверждение и откладывание прямо из уведомления.
- Списки на сегодня, неделю и месяц; теги, приоритеты и поиск.
- Тихие часы, утренняя и вечерняя сводки, настойчивые и предварительные напоминания.
- Импорт и экспорт: JSON, iCalendar, CSV.
- В планах — интеграция с календарями.

## Приватность

Тексты напоминаний шифруются ключом, который есть только у пользователя. Сервер хранит расписание и зашифрованные данные и прочитать их не может. Распознавание речи и разбор фраз выполняются на собственном сервере, без внешних сервисов.

## Технологии

Python, aiogram, SQLite, локальное распознавание речи, Telegram Mini App, Docker Compose.

## Разработка

1. Скопируйте `.env.example` в `.env` и укажите токен бота от [@BotFather](https://t.me/BotFather).
2. Запуск без Docker: `uv sync && uv run python -m bot`.
3. Запуск в Docker с перезапуском при изменениях: `docker compose -f compose.yml -f compose.dev.yml watch`.

Проверки: `uv run ruff check . && uv run mypy bot tests && uv run pytest`.

Ветки: `main` — релизы, `develop` — интеграция, работа ведётся в `feature/*`, `fix/*`, `chore/*` от `develop`.
